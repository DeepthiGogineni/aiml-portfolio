# Deepthi Pinninti: AIML Portfolio

Portfolio for the AIML course at Indiana Wesleyan University.

- Artifact 1 (Workshop 1.5): The Machine Learning Algorithm Map, an infographic of 15 algorithms sorted by learning type and application domain.

- Artifact 2 (Workshop 2.4): Inside a Neural Network, a 14-slide presentation on the six components of a neural network, with TensorFlow Playground experiments.

Built with plain HTML and CSS and hosted on GitHub Pages.
