Introduction

This artifact is my submission for Workshop 1.5 in the AIML course at Indiana Wesleyan University. When I first read about machine learning algorithms, I could repeat the names but could not say which one to pick for a given problem. This artifact is the reference I wished I had at that point: ten well-known algorithms, each placed by the kind of data it works on, how it learns, and a real example of where it is used.

Description

The artifact is an infographic plus the notes behind it. The infographic sorts ten algorithms into four application domains (Tabular Data, Computer Vision, Natural Language, Generative AI) and a cross-domain band for methods that do not belong to one domain. Each card shows the learning type, a one-sentence explanation, a real use, and a small diagram. Below the infographic, every algorithm has its own explanation with step-by-step working and a diagram made from real example data.

Objective

To classify ten key machine learning algorithms by learning style and application domain, and to explain each one clearly enough that a reader with no machine learning background can tell what it is for and when to use it.

Process

  1. Started from the ten algorithms suggested in the assignment and checked each one against the course videos and standard references.
  2. For each algorithm I wrote down the data it works on, whether it needs labels, and one real use.
  3. Placed each algorithm in a domain. K-Means and PCA went into a cross-domain band, SVM went under Computer Vision with tags for its other uses, and the Transformer went under Natural Language with a Generative AI tag.
  4. Built a diagram for every algorithm from real example data (scikit-learn datasets), so each picture shows actual behavior, such as one tree against a forest.
  5. Designed the infographic in HTML and CSS, exported it as PNG and PDF, checked text size and contrast, then wrote the explanations and the reflection.

Tools

  • Python (scikit-learn, SciPy, matplotlib) to generate the diagrams from real data.
  • HTML and CSS for the infographic layout, and Playwright to export it as a high resolution image.
  • Course videos and textbook papers as sources for the definitions.
  • An AI assistant (Claude) to help draft the descriptions and code. I checked every explanation against my sources and edited the wording.

Value Proposition

It shows that I can take a broad technical subject, organize it, and explain it in plain language to people who are not specialists. Recommending an AI approach to a business team needs exactly that skill.

Unique Value

Most algorithm charts sort by one idea. This one uses two, the type of data and the way the algorithm learns, and it is open about the edges. SVM, K-Means and PCA work across domains, and GPT, BERT and diffusion models learn without human-written labels, so they do not fit the old supervised and unsupervised split. Every diagram is drawn from real data, not copied from a textbook.

Relevance

It connects to my Salesforce work. Einstein Prediction Builder uses tabular methods, and Agentforce is built on large language models, which are Transformers. It also connects to my Workshop 1.4 project, where a Decision Tree sorted fruit photos with about 54 percent accuracy. This map shows why a CNN suits that kind of data better.

Deep Dives

Ten Algorithms Explained

These are the ten algorithms on the map. Each has a step-by-step explanation, a real-world use, and a diagram drawn from real example data.

SupervisedTabular Data

Linear Regression

Linear Regression predicts a number by fitting a straight line (or a flat plane when there are several inputs) through the training examples.

How it works

  1. Write the model as price = b0 + b1 x size, where b0 is the starting value and b1 is how much the price rises for each extra square metre.
  2. For any choice of b0 and b1, measure the error of every house: the gap between its real price and the line (the orange segments).
  3. Square those errors and add them up. Pick the b0 and b1 that make this total as small as possible. This is called least squares.
  4. To predict a new house, put its size into the line.

Real-world use: Predicting house prices from size, location score and age. The same idea is used for sales forecasts and energy demand.

Strength: it is fast and easy to explain, because each coefficient says how much one input matters. Limit: it only sees straight line patterns and one extreme outlier can pull the line off.

SupervisedTabular Data

Decision Tree

A Decision Tree classifies by asking a chain of yes/no questions about the input, like a flowchart that the computer builds from examples.

How it works

  1. Look at every input and every possible cut-off (for example, income above 40,000).
  2. Choose the question that splits the training examples into the purest groups, using a score such as Gini impurity.
  3. Repeat inside each new group until a group is pure, too small, or the tree reaches a depth limit.
  4. To classify a new case, follow the answers from the top down to a leaf, and give the label that most of that leaf's examples had.

Real-world use: Loan approval: income, debt and credit history lead to approve or decline, and the path can be shown to the customer.

Strength: the rules are readable by anyone. Limit: a deep tree memorizes the training data and does badly on new cases, which is why forests were invented.

SupervisedTabular Data

Random Forest

A Random Forest is many Decision Trees that vote. One tree is unstable, but the average opinion of many different trees is steady.

How it works

  1. Draw many random samples of the training rows, with repeats (bootstrap samples).
  2. Grow one tree on each sample. At each split only a random subset of the inputs is allowed, so the trees are different from each other.
  3. To predict, let every tree vote and take the majority (or the average for a number).
  4. Because the mistakes of the trees are mostly different, they cancel out. The picture shows the forest's boundary is smoother than one tree's.

Real-world use: Fraud detection: hundreds of trees score each card transaction on amount, place, time and history.

Strength: accurate with little tuning, and it handles messy tables. Limit: it is harder to explain than a single tree and slower to run.

SupervisedTabular, Computer Vision, Natural Language

Support Vector Machine (SVM)

An SVM separates two classes with the line (or plane) that leaves the widest possible empty gap between them.

How it works

  1. Plot the training examples and look for a boundary that splits the classes.
  2. Among all boundaries that work, pick the one with the biggest margin, the distance to the nearest points of each class.
  3. Only those nearest points, the support vectors (circled), decide the boundary. The rest of the data could move without changing it.
  4. If the classes cannot be split by a straight line, a kernel lifts the data into a space where they can, and the boundary bends when it is brought back.

Real-world use: Image classification on hand-made image features, and sorting documents into topics from word counts.

Strength: works well on small and medium data with many features. Limit: it gets slow on very large data and does not give probabilities directly.

SupervisedTabular Data

Gradient Boosting

Gradient Boosting builds a strong model by adding small, weak trees one at a time, each one trained to fix the errors the earlier trees left behind.

How it works

  1. Start with a simple guess, such as the average of the answers.
  2. Measure the errors (residuals) of that guess on every training row.
  3. Train a small tree to predict those errors, and add a fraction of its output (the learning rate) to the guess.
  4. Repeat for hundreds of rounds. The three panels show the curve getting closer to the data as trees are added.

Real-world use: Customer churn prediction: telecom and subscription companies score who is likely to leave. Libraries such as XGBoost and LightGBM are common winners on tabular data.

Strength: often the most accurate method for tables. Limit: it needs tuning, and too many rounds will fit the noise (the last panel starts to).

UnsupervisedTabular, Computer Vision

K-means Clustering

K-means groups unlabeled data into k clusters of similar points. It finds the groups itself, with no answers provided.

How it works

  1. Choose k, the number of groups you want.
  2. Place k centres at random.
  3. Assign every point to its nearest centre.
  4. Move each centre to the average position of the points assigned to it.
  5. Repeat the last two steps until the centres stop moving.

Real-world use: Customer segmentation: group shoppers by spending, frequency and recency, then design a campaign for each group.

Strength: simple and fast. Limit: you must choose k (the elbow method helps), it assumes round clusters of similar size, and it is thrown off by unscaled features and outliers.

UnsupervisedTabular, Computer Vision

Principal Component Analysis (PCA)

PCA reduces many columns to a few new ones that keep most of the information, by finding the directions along which the data varies most.

How it works

  1. Center the data (and usually scale each column).
  2. Find the direction with the most spread. That is the first principal component (PC1 in the picture).
  3. Find the next direction with the most spread that is at right angles to the first, and so on.
  4. Keep only the first few components. In the example, PC1 alone holds about 94% of the variation, so two columns become one with little loss.

Real-world use: Reducing data dimensions: compress hundreds of sensor readings, draw wide data on a 2D chart, or remove noise before another model.

Strength: simplifies and speeds up later steps. Limit: it only finds straight line patterns, and the new components are hard to name.

Supervised (usually)Computer Vision

Convolutional Neural Network (CNN)

A CNN recognizes images by sliding small filters across them, building from edges to shapes to whole objects.

How it works

  1. A filter, a small grid of numbers, slides over the image and produces a feature map that lights up where its pattern appears (here, vertical and horizontal edges).
  2. Pooling shrinks each map by keeping the strongest responses, so the network cares less about exact position.
  3. Many layers are stacked. Early layers find edges, middle layers find textures and parts, and later layers find objects.
  4. A final layer turns the features into class probabilities. Training on labeled images adjusts the filters automatically through backpropagation.

Real-world use: Image recognition: reading medical scans, unlocking a phone with your face, sorting photos.

Strength: learns its own features, so no hand-made measurements are needed. Limit: it needs a lot of labeled images and a GPU, and its decisions are hard to explain.

Self-supervised (varies by training)Natural Language, Generative AI

Transformer (GPT and BERT)

A Transformer reads text by letting every word look at every other word and decide which ones matter. GPT and BERT are two ways of training it.

How it works

  1. Split the text into tokens and turn each into a list of numbers (an embedding), with its position added.
  2. Self-attention: each token asks which other tokens help explain it. In the picture, "it" pays most attention to "cat". These attention weights are the heat map.
  3. Many attention layers are stacked, so meaning gets richer layer by layer.
  4. GPT is trained to predict the next token, so it can write text one token at a time. BERT is trained to guess hidden words using both sides of the sentence, so it is strong at understanding text. Neither needs human-written labels.

Real-world use: Text generation (chat assistants, drafting, code help) with GPT, and text classification and search ranking with BERT.

Strength: handles long context and scales well. Limit: very expensive to train, and generated text can sound sure while being wrong. The attention picture here uses illustrative values.

Self-supervised / UnsupervisedGenerative AI, Computer Vision

Diffusion Model

A diffusion model creates images by learning to remove noise. Generation starts from pure noise and cleans it up step by step.

How it works

  1. Forward process (training): take a real image and add a little noise, again and again, until only noise is left. The picture shows a real digit being destroyed this way.
  2. Teach a neural network, at every step, to predict the noise that was added. No human labels are needed.
  3. Generation: start from random noise and let the network remove a bit of noise at each step, running the picture right to left.
  4. For text-to-image, the text prompt is turned into numbers and guides each cleaning step. Stable Diffusion does this in a compressed space to save computation.

Real-world use: Image generation: Stable Diffusion, product mockups, concept art.

Strength: very detailed, varied images. Limit: many steps make it slow and costly, and it raises questions about copyright and misuse.

Classification Process

How I Sorted the Algorithms

Question 1: What data does it work on?

This sets the column. An algorithm goes where it is most often used, so Random Forest sits with tabular data and the CNN sits with computer vision.

Question 2: How does it learn?

Supervised algorithms learn from labeled examples. Unsupervised algorithms look for patterns without labels. Self-supervised algorithms make their own labels from the data, for example by hiding a word and guessing it.

Question 3: How are they related?

Random Forest and Gradient Boosting both grow out of the Decision Tree. The Transformer sits inside deep learning and is the base of today's large language models. A nested diagram at the top of the map shows how AI, machine learning, deep learning and generative AI fit inside each other.

K-Means and PCA

Both work on tables and on images, so a single column would mislead. I gave them a separate band with tags for both domains.

SVM

An SVM is a general classifier. The assignment gives image classification as its example, so I placed it under Computer Vision and tagged its use on tables and text.

The Transformer

The assignment asks for supervised or unsupervised. GPT and BERT train on text with no human labels, so supervised is wrong and unsupervised hides how they work. I added a self-supervised badge and noted that they are often fine tuned with labels afterwards. I placed the Transformer under Natural Language and tagged it Generative AI because it also writes text.

Diffusion models

Books describe them as unsupervised or self-supervised. I used self-supervised because the training signal, the noise that was added, comes from the data itself.

Why these ten

The assignment asks for at least eight to ten algorithms. I kept the ten suggested ones because together they cover every domain and every learning type, and because I could explain each one properly. A longer list would have made each explanation thinner.

Conclusion

Algorithms are tools for different jobs. The useful question is not which one is best but which one fits the data and the labels you have. Tables usually call for tree based methods, images for convolutional networks, text for Transformers, and new content for generative models.

The map also shows that the categories overlap. Being open about those edge cases made the framework more honest and more useful.

Reflection

Artifact Reflection

Lessons Learned

Before starting this assignment, I knew many machine learning algorithms by name, but I understood them mostly as separate concepts. I had used a Decision Tree in the fruit classification workshop and was familiar with GPT and diffusion models, but I had never compared them within one framework. Creating this visual map helped me understand how different algorithms relate to one another and why choosing the right model depends on the problem, the type of data, and the learning approach. It also helped me move beyond memorizing definitions and focus on how these algorithms are applied in real-world situations.

One of the biggest challenges was classifying algorithms that can be used across multiple domains. SVM, K-Means, and PCA are not limited to a single type of data or application, so I had to think carefully about how to represent their flexibility. Transformers were especially interesting because models such as GPT and BERT often learn through self-supervised methods. Although the assignment focuses on supervised and unsupervised learning, I included self-supervised learning as an additional category to make the distinction clearer. Diffusion models also helped me recognize that generative AI involves different training approaches and cannot always be explained using only traditional categories.

Creating diagrams and connecting the concepts to practical examples made the learning experience more meaningful. Comparing a single Decision Tree with a Random Forest helped me understand how combining multiple trees can improve prediction stability. Exploring how diffusion models gradually transform noise into meaningful images also made the image-generation process easier to understand. These activities showed me that visual explanations can make complex technical concepts more accessible than definitions alone.

The strongest connection for me was with my Workshop 1.4 Decision Tree project, where my fruit classification model achieved approximately 54% accuracy. This result helped me recognize the importance of selecting suitable features and algorithms. A Decision Tree can learn from numerical features extracted from images, while a Convolutional Neural Network can learn visual features directly from image pixels. Understanding this difference gave me a clearer idea of why certain algorithms perform better for particular tasks.

My experience as a Salesforce Developer working with Agentforce also made the NLP and generative AI sections especially relevant. I now have a better understanding of how language models fit into the broader machine learning landscape rather than viewing them as standalone AI tools. Overall, this assignment strengthened my ability to compare algorithms, understand their limitations, and select suitable approaches based on the task. As a next step, I plan to build small coding examples for tabular data, computer vision, NLP, and generative AI so I can apply these concepts and evaluate their performance through hands-on experimentation.

Audience Customization

This artifact is for classmates, instructors and hiring managers who know some machine learning terms but are not specialists. The explanations use plain words, each algorithm has one example from everyday life or business, and the decision strip at the bottom of the map turns it into a quick guide.
